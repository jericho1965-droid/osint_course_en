# Contribution Guide – Practical OSINT Course

Thank you for your interest in contributing to this course! Community contributions are essential to keeping the content, scripts, and legal references up to date.

## How to Contribute

### 1. Reporting Bugs or Inaccuracies

If you encounter a problem with the Python scripts or an error in the educational material:

- Check the Issues section to see whether the problem has already been reported.
- Open a new issue describing the problem in detail, including the execution environment (e.g., operating system and Python version) and any error messages.

### 2. Proposing Changes or New Modules

- Fork the repository.
- Create a dedicated branch for your feature or fix:

```bash
git checkout -b feature/feature-name
```

- Ensure that Python scripts follow PEP 8 conventions and are well documented.
- Run automated tests and checks before committing.
- Submit a pull request (PR) explaining your changes.

## Code and Style Conventions

- **Python:** Use standard Python 3.8+ syntax.
- **Language:** All primary documentation and code comments must be in English.
- **Law and ethics:** Do not include tools or examples that promote illegal or unauthorized use of OSINT.
