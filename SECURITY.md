# Security Policy

## Supported Versions

We currently provide security updates and fixes for the following versions:

| Version | Supported |
| --- | --- |
| Main/HEAD | :white_check_mark: |
| < 1.0.0 | :x: |

## Reporting a Vulnerability

The security of our tools and the privacy of our users are top priorities.

If you identify a security vulnerability in the Python scripts or course platform:

- Do not open a public issue.
- Send a detailed report to the maintainer by email or through GitHub's Private Vulnerability Reporting feature.
- Describe the steps required to reproduce the vulnerability and its estimated impact.

We aim to respond within 48 hours of receiving the report and to release a fix as soon as possible.
